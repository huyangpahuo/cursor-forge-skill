# cursor-forge-skill

可以把我们常用的windows鼠标指针转换为你的网站的鼠标指针!

## 使用方法

### 第一步

将以下话复制给 chatgpt deepseekharness  claude 等agent让它帮你下载该skill

```
帮我下载https://github.com/huyangpahuo/cursor-forge-skill这个skill到此工作目录
```

### 第二步

前往鼠标指针网站如[致美化 ](https://zhutix.com/tag/cursors/) [custom-cursor](https://custom-cursor.com/) [deviantart](https://www.deviantart.com/search?q=cursor)  [rw-designer](https://www.rw-designer.com/cursor-library?search=)  [cursors-4u](https://www.cursors-4u.com/) [Github](https://github.com/search?q=windows+cursor+theme&type=repositories&utm_source=)

我推荐这款[AnyaCursor](https://github.com/Rachit-Pal/AnyaCursor)

你可以复制这句话给agent

```
我要下载https://github.com/Rachit-Pal/AnyaCursor这个鼠标指针到此工作目录
```

### 第三步

把这句话复制给agent让它帮你把鼠标指针转换并安装到你当前的网站

```
用cursor-forge skill 帮我将刚下载的cursor转换为我的网站版本
```

当前实测成功的有 

Astro   Hugo  Hexo  VitePress  VuePress  Next.js  Nuxt  WordPress  以及纯静态 HTML

可以让agent根据你的网站调整
